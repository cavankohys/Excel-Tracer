Model Tracer v1.6.4

Privacy & data handling

Model Tracer performs its workbook analysis inside the Excel Office Add-in runtime. This production package contains static HTML, JavaScript, CSS, JSON and image files only.

What the add-in reads

  • Selected cells, formulas, values and formats needed for tracing, formatting and audit checks.
  • Workbook worksheet and defined-name metadata when the user runs workbook-level audit functions.

What leaves Excel

The Model Tracer application code does not transmit workbook content to an application server, analytics service or telemetry endpoint. The add-in loads Microsoft's required Office.js library from appsforoffice.microsoft.com.

Local browser storage

The add-in stores two non-sensitive UI preferences locally: whether same-sheet formulas are reset to black and whether text hardcodes are included in automatic formatting. Workbook data is not written to localStorage.

Clipboard

When the user explicitly clicks Copy, trace or audit text is written to the user's system clipboard.

Permissions

The manifest requests ReadWriteDocument because tracing and auditing require workbook reads and formatting actions change cell font colour or create an audit report sheet.
